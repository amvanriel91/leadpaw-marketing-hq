LEADPAW MARKETING HQ - GITHUB PAGES PACKAGE

This is a static, browser-based prototype. It does not include live AI APIs, cloud database sync, social publishing, or automated web prospect discovery.

PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub.
2. Create a NEW repository named: leadpaw-marketing-hq
3. Set repository visibility to PUBLIC (required for GitHub Free Pages on a personal account in the standard setup).
4. Create the repository.
5. Choose Add file > Upload files.
6. Upload index.html from this folder. Do not upload the ZIP itself.
7. Commit the upload to the main branch.
8. Open repository Settings > Pages.
9. Under Build and deployment, choose Deploy from a branch.
10. Select branch main and folder /(root), then Save.
11. Wait for GitHub Pages to publish. The site URL will be shown on the Pages settings screen, normally https://YOUR-USERNAME.github.io/leadpaw-marketing-hq/

DATA NOTE
The prototype stores workspace data in browser localStorage on the device/browser being used. It is not a secure cloud CRM and does not sync between devices. Export backups regularly. Do not store sensitive personal information in this prototype.

For a private repository or custom domain, check GitHub's current Pages plan rules before relying on free hosting.
